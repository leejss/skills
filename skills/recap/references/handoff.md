# Handoff mode

Create an operational handoff that lets another person or a future Codex task continue without reconstructing the conversation.

## Optimize for continuation

Lead with the current state and the next useful action. Include only context that changes how the work should continue:

- objective and agreed scope
- current status
- completed work and observable results
- decisions, rationale, and meaningful rejected alternatives
- relevant files, artifacts, commands, or external resources
- constraints, assumptions, and user preferences
- validation actually performed and its outcome
- unresolved questions, blockers, and risks
- ordered next steps with a clear starting point

Distinguish completed, in-progress, proposed, and unverified work. Never convert an intention into a completed result or invent validation that did not occur.

## Keep it actionable

Prefer exact names and paths when they help the next person resume. Preserve project-specific context needed for continuation, but remove conversational filler and explanations that do not affect the work.

When the conversation changed direction, record the final direction and briefly note the superseded approach only if it prevents repeated work or explains an important constraint. Do not write a tutorial or reproduce the conversation chronologically.
